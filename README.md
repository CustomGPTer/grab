# Grab

Grab is a free video and audio downloader for Android with its own ad-blocking browser. Open a page with a video on it, tap the round Download button, choose a size, and the file is saved to your phone. It has no adverts, no accounts, no tracking and no paid version.

This branch holds the app's public website:

- [Home page](https://customgpter.github.io/grab/)
- [How it compares with other downloaders](https://customgpter.github.io/grab/compare.html)
- [Release notes](https://customgpter.github.io/grab/releases.html)

- [Terms of use](https://customgpter.github.io/grab/terms.html)
- [Licences and credits](https://customgpter.github.io/grab/licences.html)

The latest version of the app is on the [Releases page](https://github.com/CustomGPTer/grab/releases/latest). The app's source code, under the GNU General Public License version 3, is on the [`source` branch](https://github.com/CustomGPTer/grab/tree/source).

The site is plain HTML and CSS with no scripts, cookies or tracking, and is served by GitHub Pages from the `main` branch.
